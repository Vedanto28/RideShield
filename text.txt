### 🚀 Quick 3-Step Free Deployment Checklist

#### Step 1: Deploy Backend to Render.com (5 mins)
1. Push your code to GitHub.
2. Sign up on [Render.com](https://render.com) (Free).
3. Click **New +** → **Web Service** → Select your GitHub repo.
4. Set Build Command: `pip install -r requirements.txt`
5. Set Start Command: `gunicorn main:app -w 2 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000`
6. Add Environment Variables from `backend/.env`.

#### Step 2: Deploy Insurer Dashboard to Cloudflare Pages (3 mins)
1. Sign up on [Cloudflare Pages](https://pages.cloudflare.com) (Free).
2. Connect GitHub → Select `insurer-dashboard/frontend-web`.
3. Set Build Command: `npm run build` and Output Directory: `dist`.

#### Step 3: Build Android APK for Rider App (2 mins)
In `rider-app/`:
```bash
npx eas-cli build -p android --profile preview
```
This generates a direct downloadable `.apk` link for mobile users completely free!
